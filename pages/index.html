Zwei Wege, ein Ziel

Cloud-API oder lokale API — deine Entscheidung

Beide Modi werden von der Integration nativ unterstützt und beim Einrichten direkt gegen das Gateway getestet.

Cloud-API

  • Voller Funktionsumfang inkl. Steuerung
  • Betriebsmodi für Batterie, Wallbox, Wärmepumpe u. a.
  • Parameter wie SOC-Grenzen, Ladeziele, Konstantstrom
  • Zugriff via Cloud API Key (empfohlen) oder E-Mail/Passwort als Fallback
  • Automatische Token-Erneuerung ohne Reauth-Aufforderung

Lokale API

  • Direkt am Gateway: GET /v2/point
  • Kein Solar Manager Account nötig
  • Funktioniert ganz ohne Internetverbindung
  • Tages-Energiewerte werden lokal integriert und überleben Neustarts
  • Verfügbar ab Version 1.5.0

In wenigen Minuten

Installation über HACS

Benutzerdefiniertes Repository hinzufügen

HACS → Integrationen → ⋮ → Benutzerdefinierte Repositories → URL https://github.com/Soardiac/ha-solarmanager, Kategorie Integration.

Installieren und neu starten

„Solarmanager" suchen, installieren und Home Assistant neu starten.

Verbindungsmodus wählen

Einstellungen → Geräte & Dienste → Integration hinzufügen → Solarmanager. Cloud API Key (Profil → Cloud-API-Schlüssel im Solar Manager Portal) oder lokale Gateway-IP eintragen.

Häufige Fragen

FAQ

Ist das eine offizielle Solar Manager Integration?

Nein. Die Integration ist inoffiziell und wird unabhängig gepflegt. Solar Manager AG ist dafür nicht verantwortlich und bietet keinen Support dafür.

Funktioniert die Integration ohne Internet?

Ja, ab Version 1.5.0 im lokalen Modus. Home Assistant kommuniziert dann direkt mit der REST-API des Gateways im lokalen Netzwerk — nur Sensoren, kein Account nötig.

Was ist der Unterschied zwischen Cloud- und lokalem Modus?

Der Cloud-Modus bietet den vollen Funktionsumfang inklusive Steuerung. Der lokale Modus liefert nur Sensordaten direkt vom Gateway, dafür ohne Account und ohne Cloud-Abhängigkeit.

Kann ich zwischen den Modi wechseln?

Nicht direkt — ein Wechsel erfordert das Löschen und Neu-Einrichten der Integration. Zugangsdaten, Gateway-ID, Host oder Protokoll lassen sich dagegen jederzeit ohne Neueinrichtung ändern.
