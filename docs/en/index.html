Integrate Solar Manager with Home Assistant

Home Assistant integration for Solar Manager (solar-manager.ch) – sensors and control via the cloud API or the local gateway API (unofficial).

Source code, releases, questions and HACS installation: Solar Manager Home Assistant integration on GitHub

Features

Connects your Solar Manager gateway to Home Assistant. There are two modes to choose from:

  • Cloud API – the full feature set, including control of battery, wallbox, heat pump and other devices.
  • Local API – sensors only, straight from the gateway, with no internet connection and no account.

New devices on the gateway are detected automatically, and daily energy values work with the Energy Dashboard and survive restarts.

Requirements

Home Assistant 2025.8 or newer and a Solar Manager gateway on your network.

  • Cloud mode – a Solar Manager account, the gateway ID (smId) and a cloud API key from the Solar Manager portal.
  • Local mode – just the gateway's IP address on your local network. No account, no internet needed.

Installation

  1. HACS → Integrations → ⋮ → Custom repositories → https://github.com/Soardiac/ha-solarmanager, category Integration.
  2. Install “Solarmanager”, then restart Home Assistant.
  3. Settings → Devices & services → Add integration → Solarmanager. Pick the connection mode and enter either the cloud API key or the local gateway IP.

Or install it manually: copy the folder custom_components/solarmanager into <config>/custom_components/ and restart Home Assistant.

Creating a cloud API key

For new setups the cloud API key is the only supported route – Solar Manager is phasing out email and password authentication.

  1. In the Solar Manager portal → Edit profile → Cloud API keys → Add API key.
  2. Leave the end date empty, enable all four scopes, and leave “Allow renewal” switched off.
  3. Copy the generated token straight away – it cannot be retrieved later – and enter it when you set up the integration.

Use cases

  • Use surplus PV – switch on a wallbox, smart plug or water heater as soon as PV output exceeds household consumption.
  • Protect the battery – only run automations while the battery SOC is above a threshold, to avoid unwanted deep discharge.
  • Daily dashboard – visualise self-sufficiency and self-consumption rates and track them over time.
  • Avoid load peaks – get a notification or reduce controllable loads when grid draw runs high.
  • Presence-based charging – switch the wallbox charging mode when someone gets home and the SOC is below 50 %.

Example automation

Switch the wallbox to solar-only mode as soon as more than 500 W is being fed into the grid:

automation:
  alias: "Wallbox solar mode on PV surplus"
  trigger:
    - platform: numeric_state
      entity_id: sensor.solarmanager_grid_power
      below: -500
      for: "00:02:00"
  action:
    - action: select.select_option
      target:
        entity_id: select.my_wallbox_mode
      data:
        option: "Only Solar"

Troubleshooting

  • All entities show as “unavailable” – usually the cloud is unreachable or the credentials have expired. Fix it under Devices & services → Re-authenticate.
  • A device does not show up – new devices are detected automatically, normally within about 60 seconds. If not, reload the integration.
  • Values update too rarely – lower the scan interval in the options (recommended minimum: 10 s).
