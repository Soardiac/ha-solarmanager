Solar Manager in Home Assistant integrieren

Inoffizielle Integration für Solar Manager (solar-manager.ch) – Sensoren und Steuerung über Cloud-API oder lokale Gateway-API.

Quellcode, Releases, Fragen und HACS-Installation: Solar Manager Home Assistant Integration auf GitHub

Features

Verbindet dein Solar Manager Gateway mit Home Assistant. Zwei Modi stehen zur Wahl:

  • Cloud-API – voller Funktionsumfang inkl. Steuerung von Batterie, Wallbox, Wärmepumpe und weiteren Geräten.
  • Lokale API – nur Sensoren, direkt vom Gateway, ganz ohne Internet und ohne Account.

Neue Geräte am Gateway werden automatisch erkannt, Tages-Energiewerte sind Energy-Dashboard-tauglich und überstehen Neustarts.

Voraussetzungen

Home Assistant ≥ 2025.8 und ein Solar Manager Gateway im Netzwerk.

  • Cloud-Modus – ein Solar Manager Account, die Gateway-ID (smId) sowie ein Cloud API Key aus dem Solar Manager Portal.
  • Lokaler Modus – nur die IP-Adresse des Gateways im lokalen Netzwerk. Kein Account, kein Internet nötig.

Installation

  1. HACS → Integrationen → ⋮ → Benutzerdefinierte Repositories → https://github.com/Soardiac/ha-solarmanager, Kategorie Integration.
  2. „Solarmanager" installieren, Home Assistant neu starten.
  3. Einstellungen → Geräte & Dienste → Integration hinzufügen → Solarmanager. Verbindungsmodus wählen und Cloud API Key oder lokale Gateway-IP eintragen.

Alternativ manuell: Ordner custom_components/solarmanager in <config>/custom_components/ kopieren und Home Assistant neu starten.

Cloud API Key erstellen

Für Neueinrichtungen ist der Cloud API Key der einzig unterstützte Weg – die Authentifizierung per E-Mail/Passwort stellt Solar Manager schrittweise ein.

  1. Im Solar Manager Portal → Profil bearbeiten → Cloud-API-Schlüssel → API Schlüssel hinzufügen.
  2. Enddatum leer lassen, alle vier Scopes aktivieren, „Erneuerung erlauben" nicht aktivieren.
  3. Den generierten Token sofort kopieren – er ist danach nicht mehr abrufbar – und beim Einrichten der Integration eintragen.

Anwendungsfälle

  • PV-Überschuss nutzen – Wallbox, Smart Plug oder Boiler automatisch einschalten, sobald die PV-Leistung den Hausverbrauch übersteigt.
  • Batterie schonen – Automationen nur ausführen, wenn der Batterie-SOC über einem Schwellwert liegt, um ungewollte Tiefentladung zu verhindern.
  • Tages-Dashboard – Autarkiegrad und Eigenverbrauchsquote visualisieren und historisch verfolgen.
  • Lastspitzen vermeiden – bei hohem Netzbezug benachrichtigen oder steuerbare Lasten reduzieren.
  • Anwesenheitsbasiertes Laden – Wallbox-Lademodus wechseln, wenn jemand nach Hause kommt und der SOC unter 50 % liegt.

Beispiel-Automation

Wallbox automatisch auf «Nur Solar» schalten, sobald mehr als 500 W ins Netz eingespeist werden:

automation: alias: "Wallbox Solar-Modus bei PV-Überschuss" trigger: - platform: numeric_state entity_id: sensor.solarmanager_netzleistung below: -500 for: "00:02:00" action: - action: select.select_option target: entity_id: select.meine_wallbox_modus data: option: "Nur Solar"

Fehlerbehebung

  • Alle Entities „nicht verfügbar" – meist Cloud nicht erreichbar oder abgelaufene Zugangsdaten. Unter Geräte & Dienste → Neu authentifizieren beheben.
  • Gerät taucht nicht auf – neue Geräte werden automatisch erkannt, spätestens nach ~60 Sekunden. Sonst Integration neu laden.
  • Werte aktualisieren zu selten – Scan-Intervall in den Optionen reduzieren (empfohlenes Minimum: 10 s).
